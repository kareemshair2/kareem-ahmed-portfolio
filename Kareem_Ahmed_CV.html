01About Profile / Summary

Turning data into decisions that ship.

Data Analyst with practical experience in data management, business process automation and AI-powered solutions. I build the full chain — from a raw extract to a governed model to a dashboard a non-technical manager can actually read.

My day-to-day stack is Python (Pandas, NumPy, Matplotlib, Seaborn) for analysis, SQL for modelling and transformation, Power Query & Power Pivot for repeatable ETL and DAX data models, and Power BI, Tableau & Looker Studio for the visual layer — with Excel still doing the heavy lifting where it is the fastest tool in the room.

Alongside the technical work, I lead data operations for volunteer programs across Egyptian universities — centralized databases, automated reporting and dashboards used by leadership for real-time decisions.

Operational problems rarely need more data. They need the right model, the right chart, and one automated flow nobody has to babysit.
